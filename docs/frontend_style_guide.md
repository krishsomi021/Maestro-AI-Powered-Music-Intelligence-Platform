# Frontend Style Guide (v3 React Dashboard)

Read this file only when working on the React dashboard. It is intentionally kept out of CLAUDE.md so it does not load on every backend session.

## Colors
- Dominant color + single accent. WCAG AA contrast minimum.

## Spacing
- Strict 8px grid — all margins, padding, and gaps are multiples of 8.

## Typography
- Clean sans-serif. Clearly weighted hierarchy (heading / body / label).

## Layout
- Clearly separated section headers. No visual clutter.

## Accessibility
- Semantic HTML, keyboard navigable, ARIA labels on interactive elements.
